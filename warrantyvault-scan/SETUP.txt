WarrantyVault camera scanning setup

1) Frontend: install OCR dependency in the frontend terminal:
   cd frontend
   npm install tesseract.js

2) Replace frontend/src/App.jsx with frontend-App.jsx from this bundle.

3) Open frontend/src/App.css and append the entire contents of App.css.addition.txt at the bottom. Do not replace your existing CSS with only this addition.

4) Backend: replace backend/src/server.js with backend-server.js from this bundle.
   Add backend/src/routes/documents.js from this bundle at that path.
   Keep your existing backend/src/routes/index.js and backend/src/db.js unchanged.

5) In the Warranty Vault project root, run the SQL patch:
   mysql -u root < database_documents.sql
   If your MySQL root account has a password, use: mysql -u root -p < database_documents.sql
   Copy database_documents.sql from this bundle into the project root first.

6) Restart backend from backend folder:
   npm run dev
   It should print WarrantyVault API: http://localhost:5001

7) Start frontend in a separate terminal:
   cd frontend
   npm run dev
   Open http://localhost:5173 and choose Scan documents in the sidebar.

Notes:
- Camera access works on localhost in modern browsers; approve the camera permission prompt.
- Tesseract OCR runs in the browser and downloads its English language data the first time, so the first scan may take a while and needs internet access once.
- OCR is imperfect. Review and edit every extracted field before registering a product.
- Scanned images are stored in the local MySQL Documents table only after you press Save document only or Register product & save scan.
- This stores camera scans as JPEG images. PDF upload is not included because the requested capture mode is camera scanning.
